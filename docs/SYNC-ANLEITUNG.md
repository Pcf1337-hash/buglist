# BugList: zwei Handys koppeln

1. Auf **beiden Handys die neue Test-APK als Update** installieren und die App entsperren.
2. Auf jedem Handy die passende Person öffnen: bei dir den Kollegen, beim Kollegen dich.
   Die Namen müssen nicht gleich geschrieben sein.
3. Oben auf das **Sync-Symbol „Handys koppeln“** tippen.
4. Auf einem Handy **Code anzeigen** wählen. Auf dem anderen **Code scannen** wählen,
   die Kamera erlauben und den QR-Code erfassen. Ohne Kamera geht auch **Code stattdessen eingeben**.
5. Auf **beiden Handys** eine Rolle auswählen:
   - **Liste führen (Host):** Das Handy mit dem maßgeblichen Schuldenstand. Hier werden Schulden und Zahlungen bearbeitet.
   - **Nur ansehen:** Das Handy des Gegenübers. Es übernimmt den Host-Stand und zeigt die Beträge aus der anderen Perspektive.
6. Auf **beiden Handys „Rolle bestätigen“** drücken. Nur das Auswählen einer Rolle reicht nicht.
   Beide dürfen nicht dieselbe Rolle haben; der Wizard erklärt einen solchen Konflikt und lässt die Auswahl korrigieren.
7. Beide Apps offen lassen. Der Wizard prüft automatisch weiter und zeigt nach dem erfolgreichen Abgleich
   **„Verbindung eingerichtet“**. Dann auf **Fertig** tippen.

Beim Bestätigen von **Nur ansehen** werden die bisherigen Schulden und Zahlungen **dieser Person**
auf diesem Handy durch den Host-Stand ersetzt. Das erklärt der Wizard vorher ausdrücklich.
Andere Personen bleiben unverändert. Deshalb das Handy mit dem richtigen, vollständigen Stand als Host wählen.

## So läuft der spätere Abgleich

Änderungen auf dem Host werden nach dem Speichern gesendet. Auf dem Nur-Ansehen-Handy wird der Stand beim
Öffnen der Person oder beim Herunterziehen der Liste aktualisiert. Über das Sync-Symbol kann man ebenfalls
**Jetzt aktualisieren** wählen.

Der Abgleich braucht **Internet auf beiden Handys**. Der QR-Code tauscht den Verbindungsschlüssel aus;
er ist keine Bluetooth-Verbindung. Schulden und Zahlungen werden verschlüsselt übertragen.
Ein positiver Betrag auf dem Host erscheint auf dem anderen Handy mit umgekehrter Richtung.
Belegnummern und Zahlungen bleiben dabei zusammengehörig.

Im Nur-Ansehen-Modus ist Bearbeiten gesperrt. **Verbindung trennen** beendet die Kopplung auf diesem Handy;
die zuletzt übernommenen Daten bleiben erhalten und können danach wieder bearbeitet werden.

## Alte Daten und goldener Anhänger

Das Update übernimmt die vorhandene Datenbank. Für die neue Bezahltliste werden vorhandene Zahlungsdaten
ausgewertet; fehlende historische Bezahldaten werden als unbekannt angezeigt.

Der goldene Anhänger auf der Startseite pendelt bei Neigung und kurzen Bewegungsimpulsen.
In einer senkrechten Halterung reagiert er auf kleinere Bewegungen. Unter **Einstellungen → Goldener Anhänger**
lässt er sich ausblenden. Bei ausgeschalteten Systemanimationen bleibt er statisch.

Dieser Stand ist eine Testversion. Die Veröffentlichung erfolgt erst nach der persönlichen Freigabe.
